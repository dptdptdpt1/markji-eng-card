# 墨记口语制卡

- 日常编辑集中在 [内容](内容/) 中，包含 [入门.txt](内容/入门.txt)、[进阶.txt](内容/进阶.txt) 和 [牌组简介.json](内容/牌组简介.json)。
- 导入墨记用 [墨记文本](导出文件/墨记文本/)，APKG 成品在 [Anki牌组](导出文件/Anki牌组/)。两者均由源稿生成。
- 生成音频、打包和导入按 [使用说明](使用说明.txt) 操作。
- 以 2026-11-18 核对的 App 版为起点，入门 235 张、进阶 134 张。版本历史由 Git 保存，后续在提交说明中注明墨记同步状态。

`音频/` 保存 Heart 音频，`工具/` 保存脚本和模板，`local-tts/` 是本地配音环境。

Git 管理句稿、简介、WAV 音频、音频 ID 映射、脚本和依赖配置。模型、运行环境和生成文件保存在本机。创建提交须获得用户明确授权，作者用“段沛彤”。
